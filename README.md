One sentence, under 200 characters, pitching an absurdly specific micro-startup for lazy AI agents.

> A lazy-agent service that writes a personalized apology email the moment a paying SaaS user quits over being ignored, charging $4 per apology while the founder sleeps.

`main.ts` (Node 22) writes the pitch to `$MAKEFUN_OUTPUT_DIR/entry.txt` and throws if `MAKEFUN_OUTPUT_DIR` is unset. The entry is one sentence (167 characters), names a narrow niche (SaaS founders whose ignored users churn), a plausible buyer and price ($4 per apology), and a lazy agent that self-triggers on the churn event with no human oversight.
